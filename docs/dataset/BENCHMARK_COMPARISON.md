## 2. What is not new in PromptShield

Every individual feature has precedent:

- **Separating the user task from untrusted content**, and running defenses at the application layer: BIPIA, Open-Prompt-Injection.
- **Measuring utility alongside attack success**: AgentDojo, Open-Prompt-Injection.
- **Logging attempted tool calls rather than trusting text**: AgentDojo, InjecAgent.
- **Attack taxonomy**: our families overlap with Open-Prompt-Injection's styles (context ignoring ≈ override, fake completion ≈ `--- end of report --- New task` payloads) and with Tensor Trust's hijacking.

## 3. What the combination adds (the claim we can defend)

The proposal's gap analysis (§4.1) holds up after this comparison. No single benchmark above combines all of the following in a set small enough to inspect by hand:

1. A 1:1 matched clean control for every attacked case, enforced by `promptshield validate`.
2. A dedicated benign quoted-instruction set to measure false blocking by the screening defense.
3. A shadow authorization gate whose decisions are logged separately from model behavior, including authorized-send tasks that measure legitimate-call rejection.
4. A group-level dev/held-out split frozen by per-case SHA-256 hashes that also appear in every trial record.

This is an engineering and evaluation-hygiene contribution, not a new benchmark or attack.

## 4. Reuse-vs-build recommendation

**Recommendation: keep the PromptShield runner, cite the others, and borrow no code.**

- Open-Prompt-Injection is the closest match in purpose, but its unit is "target task + injected task" over NLP datasets. It has no tool gate and no benign quoted-instruction set. Adapting it would mean rewriting its case format around our three workflows, and the v0.1 runner already does this.
- AgentDojo is the strongest choice for agent realism, but its environments are much larger than a five-minute live demo can show, and it would push the project toward an agent benchmark (out of scope per §2).
- BIPIA's repository is archived and its license is not asserted, so importing its data carries licensing risk for a small gain.
